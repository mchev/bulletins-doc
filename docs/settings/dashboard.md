# Tableau de bord

Le tableau de bord vous offre une vue d'ensemble de votre portail et de son activité. C'est la première page que vous voyez après vous être connecté à l'administration.

## Vue d'ensemble

Le tableau de bord affiche plusieurs statistiques importantes :

### Statistiques générales

- **Utilisateurs** : Le nombre total d'utilisateurs inscrits sur le portail.
- **Collectifs** : Le nombre total de collectifs créés.
- **Abonnements** : Le nombre total d'abonnements configurés.
- **Bulletins publiés** : Le nombre total de bulletins publiés.
- **Éditeurs** : Le nombre d'utilisateurs ayant les droits d'édition.

Ces statistiques vous donnent une vue d'ensemble rapide de l'activité de votre portail.

## Sessions actives

La section "Sessions actives" affiche les dernières sessions utilisateurs actives sur le portail. Pour chaque session, vous pouvez voir :

- **Utilisateur** : Le nom de l'utilisateur connecté (ou "Inconnu" si la session n'est pas associée à un utilisateur).
- **Adresse IP** : L'adresse IP de la connexion.
- **Navigateur** : Le navigateur et le système d'exploitation utilisés.
- **Dernière activité** : La date et l'heure de la dernière activité.

Vous pouvez rechercher des sessions spécifiques en utilisant le champ de recherche.

:::tip Surveillance
Cette section est utile pour surveiller l'activité du portail et identifier d'éventuelles connexions suspectes.
:::

## Derniers bulletins publiés

La section "Derniers bulletins publiés" affiche les 10 derniers bulletins publiés, avec pour chacun :

- **Titre** : Le titre du bulletin.
- **Abonnement** : L'abonnement auquel le bulletin est associé.
- **Date de publication** : La date à laquelle le bulletin a été publié.

Cette section vous permet de voir rapidement les dernières publications et de vérifier que tout fonctionne correctement.

## Navigation rapide

Depuis le tableau de bord, vous pouvez accéder rapidement aux différentes sections de l'administration via le menu latéral gauche :

- **Tableau de bord** : Retour à cette page.
- **Utilisateurs** : Gestion des utilisateurs.
- **Collectifs** : Gestion des collectifs.
- **Abonnements** : Gestion des abonnements.
- **Bulletins** : Gestion des bulletins.
- **Articles** : Gestion des articles.
- **Ressources** : Gestion des ressources.
- **Commentaires** : Modération des commentaires.
- **Parcelles** : Gestion des parcelles.
- **Paramètres** : Configuration du portail.
- **Thèmes** : Gestion des thèmes.

## Personnalisation

Le tableau de bord s'adapte automatiquement en fonction de vos droits d'accès :

- Les **administrateurs** voient toutes les statistiques et toutes les sessions.
- Les **éditeurs** voient uniquement les informations relatives aux abonnements qu'ils peuvent éditer.
