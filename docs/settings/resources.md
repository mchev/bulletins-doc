# Ressources

Les ressources permettent de partager des documents et fichiers avec les abonnés. Elles peuvent être organisées par catégories et tags, et associées à des abonnements spécifiques.

## Créer une ressource

1. Cliquez sur "Ressources" dans la barre latérale gauche de l'administration.

2. Cliquez sur le bouton `Ajouter` en haut à droite.

3. Remplissez le formulaire de création :

   - **Nom** : Le nom de la ressource.
   - **Description** : Une description détaillée de la ressource.
   - **Fichier** : Le fichier à partager (obligatoire).
   - **Image** : Une image de vignette pour représenter la ressource (optionnel).
   - **Abonnement** : L'abonnement auquel la ressource est associée. Si aucun abonnement n'est sélectionné, la ressource sera accessible à tous les abonnés.
   - **Téléchargeable** : Indiquez si le fichier peut être téléchargé par les abonnés.
   - **Catégories** : Sélectionnez une ou plusieurs catégories pour organiser la ressource.
   - **Tags** : Ajoutez des tags pour faciliter la recherche.

4. Cliquez sur le bouton `Enregistrer`.

## Types de fichiers acceptés

Les ressources peuvent contenir différents types de fichiers :

- Documents (PDF, Word, Excel, etc.)
- Images
- Vidéos
- Autres types de fichiers selon la configuration

Le type de fichier est automatiquement détecté lors de l'upload.

## Éditer une ressource

1. Cliquez sur "Ressources" dans la barre latérale gauche.

2. Sélectionnez la ressource à modifier dans la liste.

3. Modifiez les informations souhaitées.

4. Vous pouvez également :
   - Remplacer le fichier en téléchargeant un nouveau fichier.
   - Modifier ou supprimer l'image de vignette.
   - Modifier les catégories et tags associés.

5. Cliquez sur le bouton `Mettre à jour`.

## Filtrer et rechercher des ressources

Sur la page de liste des ressources, vous pouvez filtrer selon plusieurs critères :

- **Recherche textuelle** : Recherchez par nom ou description.
- **Abonnement** : Filtrez par abonnement associé.
- **Type de fichier** : Filtrez par type de fichier (Documents, Images, Vidéos, etc.).
- **Catégories** : Filtrez par catégorie.
- **Tags** : Filtrez par tag.

## Supprimer une ressource

1. Cliquez sur "Ressources" dans la barre latérale gauche.

2. Sélectionnez la ressource à supprimer dans la liste.

3. Cliquez sur le bouton `Supprimer`.

4. Confirmez la suppression.

:::warning Suppression définitive
La suppression d'une ressource est définitive. Le fichier et l'image de vignette seront supprimés de manière permanente.
:::

## Organisation des ressources

Les ressources peuvent être organisées de plusieurs façons :

### Par catégories

Les catégories permettent de regrouper les ressources par thème ou type de contenu. Par exemple :
- Guides techniques
- Rapports
- Formulaires
- etc.

### Par tags

Les tags permettent d'ajouter des mots-clés pour une recherche plus précise. Un même tag peut être utilisé pour plusieurs ressources.

### Par abonnement

Les ressources peuvent être associées à un abonnement spécifique. Dans ce cas, seuls les abonnés de cet abonnement pourront y accéder.

Si aucune ressource n'est associée à un abonnement, elle sera accessible à tous les abonnés.

## Image de vignette

L'image de vignette permet de représenter visuellement la ressource. Elle est affichée dans la liste des ressources et peut aider les abonnés à identifier rapidement le contenu.

:::tip Meilleures pratiques
- Utilisez une image claire et représentative du contenu.
- Privilégiez une image avec un fond transparent pour un meilleur rendu.
- L'image doit être au format : jpeg, png, jpg, gif, svg.
:::
