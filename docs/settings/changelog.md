# Journal des modifications

Le journal des modifications (Changelog) vous permet de consulter l'historique des mises à jour et des nouvelles fonctionnalités de l'application.

## Accès au journal

Pour accéder au journal des modifications :

1. Cliquez sur "Changelog" dans la barre latérale gauche de l'administration.

2. Le journal s'affiche avec toutes les modifications récentes.

## Contenu du journal

Le journal des modifications contient :

- **Nouvelles fonctionnalités** : Les nouvelles fonctionnalités ajoutées à l'application (par exemple l’**envoi automatique des bulletins par e-mail** via Brevo, documenté dans [Créer un bulletin](/posts/create#envoi-automatique-par-e-mail-brevo) et [Abonnements — Brevo](/settings/plans#brevo-templates-et-envoi-automatique)).
- **Améliorations** : Les améliorations apportées aux fonctionnalités existantes.
- **Corrections de bugs** : Les corrections de problèmes identifiés.
- **Modifications techniques** : Les changements techniques importants.

Les modifications sont organisées par version et par date, avec les plus récentes en premier.

## Utilisation

Le journal des modifications est utile pour :

- **Se tenir informé** : Découvrir les nouvelles fonctionnalités disponibles.
- **Comprendre les changements** : Comprendre les modifications apportées à l'interface ou aux fonctionnalités.
- **Planifier les formations** : Identifier les nouvelles fonctionnalités qui nécessitent une formation pour les utilisateurs.
- **Résoudre les problèmes** : Vérifier si un problème rencontré a été corrigé dans une version récente.

:::tip Consultation régulière
Il est recommandé de consulter régulièrement le journal des modifications pour être au courant des évolutions de l'application.
:::

## Format

Le journal utilise le format Markdown, ce qui permet une lecture claire et structurée des informations. Les modifications sont généralement organisées par catégories :

- ✨ Nouvelles fonctionnalités
- 🐛 Corrections de bugs
- 🔧 Améliorations
- 📝 Documentation
- ⚡ Performance
